Windows用の口パク・目パチアニメーション作成アプリ

リップシンク One / Lip Sync One

立ち絵と音声から、口パクと目パチの2Dアニメーションを自動生成。LipSyncOneは、Windowsで使えるリップシンクジェネレーターです。背景透過の動画素材を書き出して、Premiere ProやDaVinci Resolveで実況・解説動画を仕上げられます。

Windows版をダウンロード 使いかたを見る

Windows 11 x64 ／ v0.3.8 ／ 音声はPC内で解析

POSITION

差分画像と音声から、
立ち絵アニメーションを作成。

ゆっくり実況やVOICEVOXなどの音声合成を使った解説動画に。WAV・MP3の音声を解析し、立ち絵の口の差分を切り替えて、セリフに合う口パク素材を作れます。

背景を透明にして書き出した動画は、いつもの編集ソフトに重ねて、字幕やカット、効果と組み合わせられます。

立ち絵の差分を切り替える、2Dのコマアニメーション素材づくりに向いています。字幕やカット編集は、お使いの動画編集ソフトで仕上げてください。

FEATURES

口パクと目パチを、ひとつの画面で。

01

口画像2枚から始められる

閉じ口と開き口の2枚から始められます。必要に応じて、3枚やRhubarb A〜H/Xの9口形にも広げられます。

02

音声はローカル解析

音声から口の動きを推定するオープンソースのRhubarb Lip Sync 1.14.0を使います。解析はPC内で行い、音声を外部へ送りません。

03

目パチ・まばたきアニメーションを自動で

開いた目と閉じた目の2枚から使えます。中割を加えれば、よりやわらかなまばたきになります。間隔やばらつきも調整できます。

04

あとから直せるタイムライン

音声の配置や画像の表示時間を調整できます。画像の位置・大きさ・回転もプレビューを見ながら編集し、あとから開き直して続けられます。

05

同じ大きさなら、かんたん配置

口や目を全身画像と同じキャンバスサイズで用意すると、位置を合わせやすくなります。小さく切り出した透過PNGも、位置を調整して配置できます。

06

背景透過のアニメーション素材を書き出せる

Premiere Proなどへ、そのまま動画素材として渡せます。ProRes 4444、FFV1、VP9 WebMに対応しています。

WORKFLOW

サンプルで試す、4つのステップ

01

画像と音声を読み込む

HOMEで新規プロジェクトを作り、アセットへ画像と音声を読み込みます。まずは無料サンプルのPNG 7枚とWAVで試せます。

02

キャラクターを追加する

「キャラクターを追加」で素材のグループを選ぶと、本体・口・目の画像をまとめて設定できます。画像と名前を確認して「適用」を押します。

03

音声を配置して、口パクを作る

キャラクターの音声行へWAVを配置すると、口パクの自動解析が始まります。あとから音量の影響度や無音しきい値を調整して、解析し直すこともできます。

04

透明動画を書き出す

最初は透明背景の「軽量WebM」が選ばれています。仕上げに使うソフトに合わせて形式を選び、表示範囲とサイズを確認して保存します。

詳しい操作手順をヘルプで見る →

背景を透明にした素材を、いつもの動画編集ソフトへ。初期設定は軽量WebMです。

LOCAL FIRST

画像も音声も、
オフラインで処理

  • 口形解析のために音声を外部サービスへ送信しません。
  • プロジェクトと素材は利用者が選んだ場所で管理します。
  • 解析エンジンはアプリに同梱。初回の追加ダウンロードは不要です。
  • アクセス解析やオンライン認証を前提にしません。

FOR

こんな制作工程に。

  • ゆっくり実況・音声合成を使った解説動画
  • 立ち絵の差分で作る口パク素材
  • Premiere ProやDaVinci Resolveで仕上げる動画
  • 透明動画を別の編集プロジェクトへ渡す工程

NOT FOR

ほかのソフトが向いていること。

  • Live2Dのようなメッシュ変形や物理演算
  • カット、字幕、色調整を含む総合動画編集
  • 連続的な表情変形や高度なキャラクターリグ
  • クラウド上での共同編集・素材管理

口パク・目パチアニメーションのよくある質問

Q1

口パクに必要な画像は何枚ですか？

口だけが違う全身画像2枚から始められます。「キャラクターを追加 → 全身画像2枚で口パク」で閉口・開口画像を指定します。本体と口を分けたパーツ方式も使えます。目パチを付ける場合は、開いた目と閉じた目の差分も用意します。差分画像の準備方法を確認してください。

Q2

日本語の音声でリップシンクできますか？

日本語のセリフを収録したWAV・MP3を読み込んで解析できます。口形は音声からの推定なので、声や発音によって結果が変わります。音声解析と調整の手順をご覧ください。

Q3

背景を透過したまま動画にできますか？

透過PNGを使い、アルファ付きProRes 4444・FFV1・VP9 WebMへ書き出せます。Premiere ProやDaVinci Resolveで仕上げる素材にはProRes 4444を用意しています。透明動画の書き出し方法を確認できます。

Q4

製品名の表記は？

日本語表記は「リップシンク One」、英語表記は「LipSyncOne」です。「Lip Sync One」も同じ製品名の表記です。

Q5

リップシンクジェネレーターとは何ですか？

音声に合わせてキャラクターの口を動かす、リップシンク（lip sync・口パク）の作成ツールです。LipSyncOneは口の差分画像を切り替えてアニメーションを作り、動画素材として書き出します。口パクの自動生成と調整方法を案内しています。

Q6

目パチ・まばたきのアニメーションも作れますか？

開いた目と閉じた目の画像から、目パチ（まばたき・瞬き）のアニメーションを自動で付けられます。半閉じの中割を加え、間隔やばらつきを調整することもできます。目パチの設定方法をご覧ください。

Q7

Windowsで立ち絵アニメーションを作るには？

Windows 11 x64用のアプリをインストールし、キャラクターの本体・口・目の差分画像と音声を読み込みます。口パクと目パチを付けた2Dアニメーションを、背景透過の動画素材として出力できます。無料サンプルから試せます。

Q8

VOICEVOXの音声やゆっくり実況に使えますか？

音声合成ソフトから書き出したWAV・MP3や録音音声を読み込めます。ゆっくり実況、ゲーム実況、解説動画のキャラクター素材づくりに使えます。音声や立ち絵は、使用する素材の利用規約に従ってください。
