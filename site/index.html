QUICK START

3ステップで制作を開始

キャラクター画像と音声があれば、基本的な動画素材を作成できます。

  1. 01

    素材を読み込む

    PNG画像とWAV等の音声をアセットへ読み込みます。読み込んだだけでは自動配置されません。

  2. 02

    レイヤーへ配置

    画像と音声をタイムラインへドラッグし、口・目の専用レイヤーを追加します。

  3. 03

    解析して書き出す

    音声クリップを解析し、Previewで確認してアルファ付き動画を書き出します。

最小構成BASE画像1枚、閉じ口と開き口の2枚、音声1本だけでも開始できます。

INSTALL

インストール

↓

インストーラー版

ReleaseのLipSyncOne_<version>_x64-setup.exeを実行します。通常はこちらがおすすめです。

▣

ポータブル版

ZIPを展開し、フォルダー内の実行ファイルから起動します。USBや別フォルダーで管理したい場合に使います。

Windowsの警告について現在はstudio-juhの自己署名による暫定配布です。入手元を確認し、必要に応じて「詳細情報」から実行してください。証明書を自動で信頼済みに登録することはありません。

ASSETS

素材の準備

画像と音声はアセットへ読み込み、必要な場所へ明示的に配置します。

✓

画像透過PNGを推奨します。全身画像と同じキャンバス寸法でも、有効ピクセルだけの小型差分でも使えます。

✓

口形閉・開の2枚、閉・中・大の3枚、Rhubarb A〜H/Xの9枚に対応します。

✓

目開・閉の2枚、開・中割・閉の3枚に対応します。

✓

音声複数クリップを直列配置できます。同じ音声を複数回置くこともできます。

ファイル名からの割り当ては、対象素材を選択して「ファイル名から自動割り当て」を押したときだけ実行されます。

LIP SYNC

リップシンクを作る

  1. 1
    口レイヤーを追加

    レイヤー欄の「＋追加」から「口 / リップシンク」を選びます。

  2. 2
    口形画像を割り当て

    簡単2枚・簡単3枚・詳細9形のいずれかを選び、画像と位置を設定します。

  3. 3
    音声クリップを解析

    リップシンクレイヤーのプロパティから解析します。結果は口形キューとしてタイムラインへ表示されます。

  4. 4
    声量補正を調整

    無音に近い区間で口が開く場合は、声量しきい値と重みを調整します。

EYE BLINK

自動目パチ

「＋追加」から「目 / 目パチ」を選び、開眼・閉眼画像を設定します。

平均間隔目パチ同士のおおよその間隔
ランダム幅規則的に見えないための時間差
閉眼フレーム目を閉じている長さ
中割設定時は閉眼の前後へ1フレーム表示

目パチレイヤーは初期状態で位置をロックします。表示のON/OFFや名前変更はロック中でも可能です。

UPDATES

更新とRhubarb

↻

アプリ更新起動時に安定版を確認します。手動では「ヘルプ → アップデートを確認」を選びます。

↓

Rhubarb本体には同梱されません。初めて解析するとき、容量とライセンスを確認して明示的にダウンロードします。

✓

安全確認固定バージョンのサイズとSHA-256を検証してから導入します。

更新前に保存未保存のプロジェクトがある間は更新を適用できません。保存後にダウンロードと再起動を実行してください。

TROUBLESHOOTING

困ったときは

Windowsが実行を止める

ファイルの入手元が公式Releaseであることを確認してください。現在は自己署名のためSmartScreenが表示される場合があります。「詳細情報」から発行元とファイル名を確認して実行します。

「Master audio preparation failed」と表示される

音声素材が移動・削除されていないか確認し、アセットを再リンクしてください。音声を読み込んだだけの場合は、マスター音声トラックへドラッグして配置します。

リップシンク解析を開始できない

マスター音声に音声クリップがあり、口レイヤーへ口形画像が設定されているか確認します。Rhubarb未導入の場合は表示される案内からダウンロードしてください。

口や目が表示されない

専用レイヤーの表示状態、アセット割り当て、位置を確認します。小型差分画像はプロパティのX / Y位置でBASEへ合わせます。

書き出した動画をWindows標準プレイヤーで再生できない

アルファ付き動画は標準プレイヤーが対応しない場合があります。Premiere Pro等へ直接読み込むか、確認用にカラーキー付きH.264 MP4を書き出してください。
