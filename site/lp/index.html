LipSyncOneは、口形・目パチ・音声をひとつのタイムラインで扱い、Premiere Proなどへ渡せるアルファ動画素材を作るための専用ツールです。

POSITION

リップシンク素材だけを、
専用工程に切り出す。

総合動画編集ソフト上で口画像を一枚ずつ並べる代わりに、差分画像と音声の処理をLipSyncOneへまとめます。

完成した透明動画は、普段使っている編集ソフトへ読み込み、字幕、カット、効果、音声ミックスと組み合わせられます。

Live2Dや総合編集ソフトの代替ではありません。少数の差分画像を切り替えるコマアニメーション素材に集中しています。

FEATURES

素材制作に必要な機能を、ひとつの画面へ。

01

2枚から始められる口形

閉口・開口の2枚、閉・中・大の3枚、Rhubarb A〜H/Xの9口形に対応します。

02

ローカル音声解析

Rhubarbで音声を解析し、声量と無音しきい値を使って静かな区間の開口を抑えます。音声を外部サービスへ送りません。

03

自動目パチ

開眼・閉眼の2枚、または中割を含む3枚で、間隔とランダム幅を調整できます。

04

編集できるタイムライン

複数音声、無音区間、画像クリップ、レイヤー順、位置、倍率を保存し、あとから開き直して修正できます。

05

小型の透過差分を自由配置

口や目を全身画像と同じキャンバスへ広げる必要はありません。位置と基準点を使ってBASEへ合わせます。

06

アルファ動画として受け渡し

ProRes 4444、FFV1、lossless VP9を書き出し後に検証し、透明度を保った素材として保存します。

WORKFLOW

読み込みから書き出しまで、4つの工程。

01

プロジェクトを作る

HOMEから新規プロジェクトを作成し、透過PNGと音声をアセットへ読み込みます。

02

口形と目を設定する

少ない画像から始め、必要に応じて3枚・9口形へ広げられます。透明余白を除いた小型PNGも配置できます。

03

音声を解析する

音量の影響度と無音しきい値を確認して解析します。結果は口形キューとしてタイムラインへ反映されます。

04

透明動画を書き出す

用途、背景、範囲、解像度を選び、代表フレームを確認してから動画を生成します。

詳しい操作手順をヘルプで見る →

EXPORT

制作工程に合わせて選べる出力形式。

透明背景を正式な出力とし、書き出し後にコーデック、フレーム数、音声情報、代表フレームの透明度を確認します。

用途形式

軽量アルファ動画lossless VP9WebM / Opus
Windowsでの確認用H.264 カラーキーMP4 / AAC・非可逆

LOCAL FIRST

画像も音声も、PCの中で処理。

  • 口形解析のために音声を外部サービスへ送信しません。
  • プロジェクトと素材は利用者が選んだ場所で管理します。
  • Rhubarbは初回利用時に内容とライセンスを確認してから取得します。
  • アクセス解析やオンライン認証を前提にしません。

FOR

こんな制作工程に。

  • 音声合成を使った実況・解説動画
  • 立ち絵の差分で作る口パク素材
  • Premiere ProやDaVinci Resolveで仕上げる動画
  • 透明動画を別の編集プロジェクトへ渡す工程

NOT FOR

対象にしていないこと。

  • Live2Dのようなメッシュ変形や物理演算
  • カット、字幕、色調整を含む総合動画編集
  • 連続的な表情変形や高度なキャラクターリグ
  • クラウド上での共同編集・素材管理
